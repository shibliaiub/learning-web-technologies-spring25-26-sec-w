Hotel Room Booking System - Task 1
Student 1: Guest Authentication & Profile

Implemented:
- MVC folder structure
- Guest registration
- password_hash() and password_verify()
- Login and logout
- Session authentication
- Role based redirect
- Remember Me cookie with hashed token stored in users.remember_token
- Profile update
- Preferred room type from room_types table
- Special requests saved to DB
- Subscribe to offers cookie for 1 year
- Upcoming booking summary card
- JavaScript validation
- PHP server-side validation
- MySQLi prepared statements

Run:
1. Copy folder to xampp/htdocs/
2. Import hotel_task1.sql in phpMyAdmin
3. Open http://localhost/hotel_task1_guest_auth_profile/views/register.php

If your MySQL password is 123456, edit config/db.php.
